# 🎨 Point of View Media / POV Media

I built POV Media because I wanted to create a space that felt less like a cluttered blog and more like a high-end digital magazine. As an IT student focusing on programming, my goal was to balance a "premium" and minimalist aesthetic with a robust technical backbone. The platform is designed for creators who believe that the way content is presented is just as important as the content itself.

## 📦 Technologies

- Backend: Python / Django

- Frontend: HTML5, CSS3, Bootstrap, JavaScript

- Styling: Custom CSS (Minimalist/Clean UI Focus)

- Database: SQLite / PostgreSQL 

- Tools: Git, Django Template Language

## 🛠 Features and Security

- User Authentication: Secure sign-up, login, and profile management.

- Content Management: Dynamic creation, editing, and deletion of blog posts.

- Categorization: Interactive category system for easy content discovery.

- Comment System: Real-time engagement via a nested, interactive comment section.

- Responsive Design: Optimized specifically for a seamless experience across devices.


## 🚀 The Process

The development process started with planning the project structure, database models, and user interface design. Django was used to handle the backend logic, routing, and template rendering while keeping the project structure organized and scalable.

The frontend interface was developed using HTML, CSS, and JavaScript with responsive design principles to ensure compatibility across different devices. Django templates were used to dynamically display content and manage reusable layouts.

The project also involved working with Django ORM for database management and implementing clean project architecture for maintainability. Throughout development, debugging, testing, and refactoring were continuously performed to improve functionality, readability, and overall performance.

Beyond the looks, the platform is a fully functional web application. It features a custom User Authentication system that manages how creators log in and interact with the site. I implemented tiered access control to ensure that while anyone can enjoy the content, only authorized users can manage posts or engage with the interactive comment system. Everything from the category management to the nested comments is handled through pure Django CRUD logic, as I wanted to prove I could build complex features without over-relying on external JavaScript libraries.

Git and GitHub were used for version control during the entire development process.
